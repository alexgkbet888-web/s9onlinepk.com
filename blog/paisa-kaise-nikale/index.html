S9 withdrawal evidence Pakistan

Document an S9 withdrawal issue with verifiable evidence

This English evidence page is for users investigating a pending, rejected or missing withdrawal. It does not promise a payment method, minimum amount or processing time because those facts require a current first-party source. The Roman Urdu page remains the concise task route; this page focuses on status definitions, records and support escalation.

Evidence updated: 2026-07-26

Name the transaction state

Pending, rejected, completed and reversed are different states. Record the exact label shown in the account, the request time and any later status change. A completed label without a matching wallet receipt is not the same as a pending request. Do not submit repeated withdrawals until the first request and its reference number are understood.

Create a transaction evidence pack

Capture the masked account identifier, amount, request timestamp, transaction or ticket reference, displayed status and masked receiving wallet. Add screenshots of the history screen and any support response. Keep the original images and note the timezone. Remove passwords, OTP values, PINs and unmasked identity details before sharing.

Check for identity and route mismatch

A mismatch between the registered account and receiving wallet can cause review or rejection, but the exact rule must come from current first-party terms. Compare names, phone formats and selected route without changing several fields at once. If the site does not expose a clear rule, ask verified support for the rule and preserve the response.

Escalate without inventing a deadline

Use the transaction reference and a short timeline when escalating. Ask support to confirm the current state, required evidence and next review point. Avoid claims such as instant payout unless a dated first-party source supports them. If the support identity cannot be verified, do not send wallet credentials or pay an additional fee to unlock a withdrawal.

Working checklist

  • Exact displayed transaction status
  • Request time, timezone and later status changes
  • Masked amount, account and receiving wallet
  • Transaction or support ticket reference
  • Dated screenshots with sensitive fields removed

Frequently asked questions

Does this page promise a withdrawal time?

No. Processing time must be verified from a current first-party source. This page explains how to document the actual state and timeline.

What should be included in a support request?

Include a masked account identifier, request time, amount, reference, displayed status and exact problem. Exclude passwords, OTP values and wallet PINs.
